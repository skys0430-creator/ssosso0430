# 참고 틀(사용자가 준 형식 자료)

발표자료·PPT·한 장 요약을 만들 때 참고하는 구조. 로고·그림·문구는 가져오지 않고 구조만 따른다.

## 1. 책자 틀(제4차 농림식품과학기술 육성 종합계획 PDF)
- 표지 → 목차 → 장 표지(전면 남색) → 장 제목 띠 → 번호 절 제목 → ■·• 글머리표 → 남색 머리 표·막대 그림
- 이 틀로 만든 결과물: `../files/2027_지역계획(안)_요약책자.pdf`, 원본 `../booklet/book.html`

## 2. 한 장 인포그래픽 틀(이미지 2장)
### 틀1: 목표·정책전략 (`인포그래픽_틀1_목표·정책전략.png`)
- 상단 띠: 기관명, 계획명(작은 알약 모양), 큰 표어 2줄(둘째 줄 강조색)
- 목표 줄: 왼쪽에 목표 2개(짧은 문장), 오른쪽에 지표 묶음 2개
  - 묶음마다 지표 2개: 지표명, 한 줄 설명, 현재값(회색 막대) → 목표값(강조색 막대)
- 전략 줄: 번호(01~04) + 짧은 이름표 + 전략 한 문장 + 세부 과제 3개, 가운데 그림을 사이에 두고 2×2 배치

### 틀2: 중점 분야 (`인포그래픽_틀2_중점분야.png`)
- 제목: "N대 중점 분야"
- 세로 칸 5개, 칸마다 같은 순서
  1. 분야 이름(색 띠)
  2. 한 줄 요약(체크 표시)
  3. As-Is(현재) 2~3줄
  4. To-Be(목표 모습) 2~3줄
  5. 그림
  6. 대표 지표: 지표명 띠 + 현재값 → 목표값 막대

## 의왕시 계획에 옮길 때의 대응(안)
| 틀 요소 | 의왕시 내용 |
|---|---|
| 표어 | 살던 곳에서 건강하게, 함께 살피는 의왕 |
| 목표 | 3대 목표 |
| 지표 묶음 | 발굴(발굴률 4.3% → 20%, 대상자 276명 → 541명) / 관리·기반(모니터링 수행률 80%, 보건소 서비스 이용률 25%) |
| 전략 2×2 | 4대 추진과업과 과업별 핵심사업 3개 |
| 중점 분야 칸 | 추진과업 4개 또는 핵심사업별 As-Is(2026 한계) / To-Be(2027 방향) / 대표 지표 |
