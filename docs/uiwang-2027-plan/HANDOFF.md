## 2. 확정된 주요 결정

### 인력·체계
- 2026년 내용(추진현황·성과)에는 겸직인력(간호)을 넣지 않음: ’26.11.30. 배치는 전담인력(복지)만 표기. 2인 체계는 2027년 계획으로만 서술
- 동별 2인 체계(2027년 계획): 전담인력(복지) 1 = 발굴·조사·계획·연계 + 모니터링 전부(개인별지원계획 안내일~종결, 최초 모니터링은 1개월 이내) / 겸직인력(간호) 1 = 의료 필요 대상자 사전조사 동행·의견 제시. 모니터링에 간호직 수행 표현 쓰지 않음
- 계획 변경: 전담인력 모니터링 → 변경(안) 작성 → 통합지원회의 재상정 → 시 전담조직이 보건소 등에 의뢰(동에서 보건소 직접 의뢰 안 함)
- 제공기관은 행복e음에 직접 입력하지 않음: 제공기관 월 1회 시에 제출 → 시가 입력
- 보건소 협업 패키지 하지 않음(보건소 협조 불가). 노인일자리 모니터링단 하지 않음
- 전담인력 배치율 100%(기준인건비 10명), 본청 다직렬은 2개 직렬(복지·간호) 유지
- 전담인력 16명 표기 시: 통합돌봄 인력 16명(전담 10, 겸직 6)

- 초고령 위험군 조사: 3개 동(청계·오전·부곡) 우선 착수 표현 쓰지 않음. 명단은 행복e음 기초연금 수급자 중 85세 이상 1인가구 추출(1~2월), 통합돌봄 신청·대상자 제외, 노인맞춤돌봄 이용자는 생활지원사 선별, 미이용자는 동 전담인력 방문(의료 필요 시 간호 동행). 1,046세대는 주민등록 통계값(명단 아님)

- Ⅲ-1 핵심사업 3번: 「개인별지원계획 수립·모니터링 내실화」[개선] (구 「동 복지·간호 협업 모니터링 체계 구축」 폐기). 발굴(선제발굴)·연계(퇴원 이원화)·관리 3축, 지표 발굴률·수립률·수행률과 짝
- 발표자료(pptx)는 사용자 요청 시에만 다시 생성

### 서비스
- 방문진료 참여의원 14개소(의과 2·한의 12) — 확충하지 않고 대상자 발굴로 이용 활성화
- 재택의료: 관내 1개소(한센복지협회 부설의원, 따로 셈) + 관외(안양) 협약 1개소 → 추가 확충 계획 없음
- 일상살핌 식사지원(일반식) → 일반식은 기존 서비스로 연계, 퇴원·급성기 치료식 맞춤형 영양식으로 개편
- 신규서비스(아직 개발 전): 이동살핌, 회복살핌 패키지, AI 돌봄로봇(Ⅲ-2 지역특화, Ⅲ-4 자체추진은 해당없음)
- 퇴원·급성기 단기돌봄 = 회복살핌 꾸러미 + 노인맞춤돌봄 퇴원환자 단기집중, 미해당 시 일상살핌
- 퇴원환자 의뢰 경로 이원화: 상급종합병원 = 안내문 → 퇴원 후 동 신청 / 종합병원 = 병원이 시 전담조직에 직접 의뢰(매뉴얼 기준), 연계수당 건당 5만원 이내
- 경기도사회서비스원은 계획서에서 제외(경기 안심이음 케어 지속 불확실)

### 명칭·표현
- 「찾아가는 통합돌봄 설명회」(「의왕살핌 이웃」 명칭 폐기), 동별 연 1회 이상(총 6회)
- 자체교육 브랜드: 「의왕돌봄마당」(의왕돌봄마당 5회 + 경기복지재단 시군 맞춤형 1회 = 연 6회, 10명 이상 참여)
- 팀장 지침: 직접 만든 지표명에 "율·비율" 쓰지 않음(→ "비중", "인원" 등). 평가 지표명(발굴률·수립률·수행률·참석률·배치율)은 유지
- "저층주택" → 표 머리는 "단독·연립·다세대 비율"로 변경
- 우선발굴필요군 표 소제목: 1) 노인 및 장애인(우선발굴필요군) / 2) 기타(우선발굴필요군 외 대상자), 2)는 "우선발굴필요군 외 돌봄 필요 노인" 한 줄
